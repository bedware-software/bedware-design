Заголовки страницы настроек — единая система из четырёх уровней, других видов заголовков нет.

1. **Страница** — `<PageHeader number title description side>`: первый блок каждой страницы. Пластина с номером (место страницы в навигации: «01», «02»…), название 16px моноширинным заглавными — то же слово, что у пункта навигации, — и описание 13px `text-muted`: о чём страница. Один на страницу. Значков в заголовке нет.
2. **Раздел** — `<SectionTitle title description>`: 13px моноширинным заглавными с маленькой пластинкой.
3. **Подраздел** — `<SectionTitle level={2}>`: 11px заглавными, `text-muted`, без пластинки.
4. **Название настройки** — `title` у `PanelRow`: 14px обычным шрифтом, описание 12px.

Толщину, размер и регистр заголовка руками не задают: уровень выбирает компонент. Описание страницы — в `PageHeader`, а не отдельным абзацем под ним.

Заголовок раздела над панелью, когда номера нет:  моноширинный 13px заглавными с маленькой пластинкой `plate` перед текстом.
React: `<SectionTitle title description level danger>`.

- `level={1}` (по умолчанию) — заголовок раздела с пластинкой и описанием 12px `text-muted`.
- `level={2}` — малый заголовок подраздела: моноширинный 11px заглавными, `text-muted`, без пластинки.
- `danger` — опасный раздел: текст и пластинка `error`.
- Подпись отдельного поля — не заголовок: для неё `<Field label>` (класс `bw-label`).
- `side` — справа от заголовка: кнопка «Добавить», счётчик. `flush` — без нижнего отступа, когда его задаёт родитель.
- Раздел с номером — `PanelHeader` внутри панели; оба заголовка у одной панели не ставят.
