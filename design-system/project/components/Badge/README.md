React: `<Badge tone="success">`.

- Тона: `neutral` — справка, `accent` — выделенное («global»), `success`, `warning`, `error`.
- Текст цвета тона на его же заливке 15%.
- Одно-два слова. Для «new» и «beta» — наклонная метка `Tag`, не бейдж.
