# bedware

bedware software — организация одного разработчика. Продукты: **Runwa** (палитра команд и клавиатурные инструменты для рабочего стола) и **Vimperium** (браузер с управлением в духе Vim). Девиз — «WRITE C0DE!».

Характер бренда — логотип: чёрный фон, плоский жёлтый, моноширинный шрифт, лёгкий наклон. Интерфейс собран из «пластин»: жёлтые детали со срезанным углом и тёмной нижней кромкой на тёмном металле. Основная тема — тёмная; у приложений есть и светлая.

## Голос

- Коротко и по делу, как подпись в хорошем инструменте: «Запускать при входе», «Команда с таким названием уже есть».
- Обычный регистр. Заглавными — только заголовок панели, метка и заголовок группы в меню.
- Кнопка называет действие глаголом: «Сохранить», «Удалить», «Изменить». Не «ОК» и не «Да».
- Клавиши показываются рядом с действием, значками системы: `⌘ K`, `↵`, `esc`.
- Без восклицаний в интерфейсе. Единственное исключение — девиз в логотипе.

## Цвет

Палитра снята с логотипа; серые чуть утеплены, чтобы рядом с жёлтым не казаться синеватыми.

- **Фон** — `bg` (чистый чёрный) везде: окно приложения, сайт, логотип. Поверхности поднимаются ступенями `surface-1` … `surface-4`.
- **Жёлтый** `yellow` — главный акцент и самый дорогой цвет; в компонентах он приходит через токен `plate`. На экране его мало: основная кнопка, плашка панели, метка, кольцо фокуса, кромка выбранной строки, включённый переключатель. Если жёлтых пятен больше трёх-четырёх, акцент перестаёт работать.
- **На жёлтом текст только чёрный** (`on-yellow`, контраст 15.9:1). Белый на жёлтом не читается (1.3:1) и запрещён.
- **Персиковый** `peach` — второй тон: ссылки (`link`), предупреждения (`warning`), вторые слова в заголовках. Рядом с жёлтым как равный не ставится.
- **Кромка** `yellow-plate` — только нижняя грань жёлтой пластины, не цвет для текста и заливок.
- **Текст** — `text` основной, `text-strong` для заголовков, `text-muted` для описаний, `text-dim` для плейсхолдеров (обычным кеглем только на `bg` и `surface-1`).
- **Состояния** — `error` (текст на нём чёрный), `success`, `warning`. Цвета мимо токенов не используются.
- **Рамки** — `border` декоративный разделитель; границы элементов управления — `border-strong`.

## Светлая тема

Светлая тема — пара тёмной, а не её негатив: пластина жёлтая с чёрным текстом в обеих темах, меняется только фон.

- **Фон белый** (`bg` в светлой теме), панели нейтрально-серые. Белый не спорит с жёлтым по тону — на тёплой «бумаге» жёлтый сливался.
- **Пластина жёлтая, текст на ней чёрный** (`plate` и `on-plate`), чёрного контура нет. Кромка снизу — жёлтый потемнее (`plate-edge`): янтарная кромка тёмной темы на белом читается коричневой.
- **Жёлтый на светлом — только площадью.** Жёлтый светлее белого фона всего в 1,3 раза, тонкая линия или текст им не видны и кажутся тусклыми. Поэтому состояние показывают заливкой: кнопка, плашка, метка, поле в режиме ввода целиком. Тонкое на фоне — токеном `accent` (в светлой теме чёрный).
- **Кольцо фокуса чёрное** (`focus`), ссылки и предупреждения тёмно-оранжевые (`link`, `warning`).
- Компоненты не знают о теме: они используют смысловые токены `plate`, `on-plate`, `plate-edge`, `accent`, `focus`, `link`, а не `yellow` напрямую. Тема включается атрибутом `data-theme="light"` на любом предке.
- Логотип в светлой теме всё равно стоит на чёрной плашке.

### Ступени и фоны

У тёмной темы есть мягкая ступень яркости — `dark-soft`: фон не чёрный, а тёплый тёмный. У светлой — фоны на выбор: `light-paper` (тёплая «бумага»), `light-soft` (бумага на тон темнее), `light-steel` (холодный голубовато-серый), `light-stone` (средне-серый, пластина на нём светлее фона). Меняются только фон, поверхности, рамки и текст; пластины и цвета статусов те же. Включается атрибутом `data-theme-variant` рядом с `data-theme`. Основные темы бренда — тёмная с чёрным фоном и светлая с белым; остальное — выбор пользователя в приложении.
## Типографика

- **Inter** — весь текст интерфейса: строки, описания, подписи кнопок. Одинаков на всех системах.
- **JetBrains Mono** — акценты: слово бренда, заголовки страниц и панелей, клавиши, метки, код, версии. Длинный текст им не набирается.
- Размеры: текст 14px, описания и подписи 12px, метки 10px. Мельче 10px ничего нет.
- Наклон — только у логотипа и метки (`Tag`), −3°. Заголовки и текст не наклоняются.

## Форма

- **Срез вместо скругления** — у жёлтых деталей и поля ввода: углы `radius-plate` (2px) плюс срез `cut` (8px). У основной кнопки срезаны два противоположных угла, у поля — правый нижний.
- **Всё остальное скруглено**: вторичные и текстовые кнопки — `radius-md`, панели, меню, диалоги и строки списков — `radius-lg`.
- **Кромка** — у жёлтой и красной пластины снизу тёмная полоса 3px; при наведении 5px, пластина приподнимается на 1px.
- **Тени** только у всплывающих слоёв (меню, диалог). Градиентов, свечения и размытия нет.
- Высоты: кнопка и компактное поле `control-sm`, поле `control-md`, поле палитры `control-lg`.

## Состояния

- **Наведение** — основная кнопка приподнимается, цвет не меняется; вторичная светлеет; текстовая получает фон `surface-3`.
- **Фокус** — жёлтое кольцо 2px с отступом 3px на `:focus-visible`. У поля вместо кольца жёлтая рамка и нижняя полоса.
- **Выключено** — диагональная штриховка `hatch-a` / `hatch-b` у кнопок, `disabled-bg` у полей. Прозрачностью состояние не показывается.
- **Выбрано** — фон на ступень светлее и жёлтая кромка слева.
- Переходы 150 мс, бегунок переключателя и свечение поля 200 мс.

## Логотип и иллюстрации

- Слово бренда — JetBrains Mono ExtraBold в контурах: обводка тем же цветом со скруглёнными стыками (5% кегля), разрядка 2%, наклон −3°; «software» — персиковым, +6.5°. Используются готовые файлы из группы **Logos**, шрифтом знак не набирается.
- Принцип вариаций: фон тот же, меняется слово — так сделаны знаки Runwa и Vimperium.
- Знак ставится только на чёрный или очень тёмный фон.
- Робот (группа **Illustrations**) — иллюстрация для сайта и пустых состояний, не стиль интерфейса. Живописная фактура в элементы управления не переносится.

## Чего не делать

- Не набирать подписи кнопок капсом.
- Не ставить белый текст на жёлтое и жёлтый текст на светлое.
- Не использовать жёлтый для больших фонов и декоративных рамок.
- Не скруглять жёлтые пластины и не срезать углы у панелей и меню.
- Не показывать выключенное состояние прозрачностью.
- Не добавлять цвета мимо токенов (`amber`, `emerald` и подобные).

## Откуда это берётся

Источник истины — репозиторий `bedware-design`: `tokens/tokens.json`, `components/components.css`, `brand/logo/`. Эта система собирается из него командой `npm run design-system`; менять значения нужно в коде, а не здесь. Компоненты — это React-пакет `@bedware/ui` (`packages/ui` в репозитории) на классах `bw-*` из `components/bundle.css`; превью здесь — те же образцы пакета, отрисованные в статичную разметку.
