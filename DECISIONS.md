# Решения по этапу 1 (2026-11-23)

Приняты владельцем на странице обзора (`index.html`). Это вход для следующего этапа: файла токенов и общего пакета компонентов.

## Бренд

| Вопрос | Решение |
| --- | --- |
| Шрифт слова бренда | JetBrains Mono ExtraBold + круглая обводка + наклон (вариант B) |
| Текст интерфейса | Гротеск для текста, моноширинный для заголовков, клавиш и меток |
| Гротеск | Inter везде, в приложениях тоже (одинаково на всех ОС, около +300 КБ) |
| Направление | C — пластины (**уточняется:** раньше кнопки C не нравились — капс и «киберпанк»; возможно, имелся в виду D) |
| Оттенок серых | Тёплые, как в `assets/brand.css` |
| Фон приложений | Чистый чёрный `#000` везде |
| Светлая тема | Нужна в приложениях, делается на следующем этапе |
| Наклон | Только логотип и редкие метки (номера разделов, «new») |
| Персиковый `#FFBF68` | Второй тон: ссылки, предупреждения, вторые слова в заголовках |
| Режимы Vim в Vimperium | Перекрасить: командный — жёлтый, ввод — персиковый |
| Claude Design | Синхронизация из кода (`/design-sync`), в Claude Design только чтение |

## Компоненты: откуда брать

| Что | Источник |
| --- | --- |
| Поле ввода: рамка, радиус, фокус | Новый вариант: устройство из Vimperium (`InputField`, три высоты), видимая рамка, жёлтый фокус |
| Высоты полей | Vimperium: 36 обычное, 40 палитра, 32 компактное |
| Шкала скруглений | Vimperium: 6 кнопки и плитки, 8 строки / меню / диалоги, 12 поля |

| Вторичная кнопка | Runwa: с рамкой |
| Hover текстовой кнопки | Runwa: `bg-accent` |
| Выключенное состояние | Новый вариант: одно значение и отдельные цвета «выключено» |
| Кольцо фокуса | Новый вариант: единое жёлтое 2px на `:focus-visible`; правила Vim-курсора Vimperium сохраняются |
| Переключатель | Vimperium: `Switch`, 36×20 и 44×24 |
| Клавиша (kbd) | Vimperium: варианты «на поле» и «на кнопке» |

## Что из этого следует и ещё не сделано

- Четыре пункта «новый вариант» (поле, hover основной кнопки, выключенное состояние, фокус) нужно нарисовать и показать перед тем, как закладывать в пакет.
- Слово бренда на JetBrains Mono: перевести в контуры (как сделано для Menlo в `tools/extract-glyphs.py`), подобрать обводку, выпустить логотип в SVG. Нынешние картинки в `inputs/` набраны Menlo.
- Inter и JetBrains Mono придётся вкладывать в приложения файлами (сейчас в них системный шрифт); метрики Inter чуть отличаются от SF Pro и Segoe UI — после замены проверить обрезку строк.
- В обоих приложениях есть цвета мимо токенов (`amber`, `emerald`, `green`, `red`) — их нужно свести к `warning`, `success`, `error`.
