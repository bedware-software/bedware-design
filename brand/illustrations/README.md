# Иллюстрации

Робот-посланник bedware для сайта и пустых состояний; в элементы интерфейса не переносится.
Исходники (PNG в полном размере) лежат у владельца в Dropbox: `Hobby/bedware.software - assets/new ambassador`.
Здесь — JPEG до 2560px по длинной стороне. Сайт `bedware-site` берёт их командой `npm run brand`.
