Пакет компонентов @bedware/ui

Общие React-компоненты для Runwa, Vimperium и сайта: код в packages/ui, стили — прежний эталон components/components.css, цвета только из tokens/tokens.json. Переключатель темы — справа вверху. Страница собирается командой npm run ui.

Страница ещё не собрана: выполните npm run ui и обновите её.
